# 📌 Sistema Kanban — Gerenciamento de Tarefas

Sistema web desenvolvido para facilitar a organização, o acompanhamento e o gerenciamento de tarefas por meio da metodologia Kanban.

A aplicação permite visualizar o andamento das atividades de forma organizada, facilitando o controle dos processos e a produtividade individual ou em equipe.

## 🌐 Acesso ao projeto

- **Sistema online:** https://kanban-cwuzmbjc4-senai-1da5.vercel.app
- **Repositório GitHub:** https://github.com/nicolasmigueltavares2007-maker/Kanban-

## 🎯 Objetivo do projeto

Desenvolver uma ferramenta digital baseada na metodologia Kanban, permitindo organizar atividades de acordo com suas etapas de execução.

O objetivo é proporcionar uma visão clara do fluxo de trabalho, facilitar o acompanhamento das tarefas e melhorar a organização das atividades.

## 📋 Sobre a metodologia Kanban

Kanban é uma metodologia visual de gerenciamento de tarefas que organiza o trabalho em etapas.

Geralmente, utiliza três categorias principais:

- **A fazer:** tarefas que ainda precisam ser iniciadas.
- **Em andamento:** atividades que estão sendo executadas.
- **Concluído:** tarefas finalizadas.

Essa organização permite acompanhar o progresso das atividades e identificar o que precisa de atenção.

## ✨ Principais funcionalidades

- Organização visual de tarefas.
- Separação de atividades por etapas.
- Acompanhamento do progresso.
- Melhor visualização do fluxo de trabalho.
- Gerenciamento e organização das atividades.

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/nicolasmigueltavares2007-maker/Kanban-.git
```

### 2. Acesse a pasta

```bash
cd Kanban-
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure as variáveis de ambiente

Caso existam integrações externas, configure as variáveis necessárias conforme o arquivo de exemplo disponibilizado no projeto.

### 5. Execute a aplicação

```bash
npm run dev
```

### 6. Acesse pelo navegador

Utilize o endereço apresentado pelo Vite no terminal, geralmente:

```text
http://localhost:5173
```

## 🚀 Build de produção

